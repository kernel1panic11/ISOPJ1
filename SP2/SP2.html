Para empezar, crearemos un disco virtual nuevo en vmware, lo normal es crear una sata pero en mi caso le he indicado NVME ya que así va más rápido, como se puede ver, el disco duro es de 10gb

       

Ahora comprobamos el sector del nuevo disco sin formatear con fdisk -l, como se puede ver el sector es de 512 bytes

       

Ahora con el comando: tune2fs -l (disco) podemos ver el tamaño del bloque

       

Ahora con df -Th, podemos ver el sistema de archivos que se usa, el espacio que está usado y el libre que hay, el poner h es opcional, pero lo pone "para humanos" entonces los representa en gb y así es más fácil de interpretar

       

La medida de clúster (Windows) y bloque (Linux), es la unidad mínima lógica donde se guardan los datos a nivel de sistema operativo, por defectos son 4096 bytes (es igual a 8 sectores) y esta medida sí que se puede cambiar, esta medida se puede cambiar cuando se formatea la partición, y cada partición del disco, puede tener una medida de bloque y sistema de archivos diferentes. este es el claro ejemplo, podemos ver cómo el archivo pesa 17 y luego su tamaño real es de 5kb

        Particiones: una partición, es un trozo físico del disco duro, pero no podemos modificar la medida del bloque, eso se hace pero terminal, un volumen es una capa de abstracción que se pone encima de las particiones y/o discos.      El gparted sirve para gestionar particiones        

Aquí hemos creado dos particiones de más o menos 5 gb cada una, esto lo hemos hecho usando la terminal, como se puede ver en la foto, las dos particiones se han hecho

       

Aquí lo que he hecho es darle un formato a la primera partición en ext4, usando el comando mkfs.ext4 -b 2048 /dev/nvme0n1p1

         

Ahora aquí lo que he hecho es darle un formato a la partición secundaria en NTFS, usando el comando mkfs.ntfs /dev/nvme0n1p1, en este caso ha tardado más que con ext4 ya que tiene que llenar la partición de ceros, desconozco el porqué

Montar partición modo temporal

   

Para empezar, montaremos de forma temporal una partición en /mnt/p1, podríamos montarlo en cualquier otra carpeta, pero lo haremos aquí, para montar la partición en este caso, lo que haríamos es con el comando mount -t ext4 /dev/nvme0n1p1 /mnt/p1 y dentro de la partición recién montada, lo que haré es crear una carpeta llamada "test" para luego reiniciar la vm y comprobar si sigue montado la partición y aparece la carpeta, lo cual ya adelanto, no es el caso

   

Nota: Cuando utilizas el comando mount, incluir la opción -t ext4 específica explícitamente el sistema de archivos (en este caso, ext4) de la partición que deseas montar. Aunque mount sí puede intentar adivinar automáticamente el sistema de archivos, no siempre lo hace o no siempre lo hace correctamente, especialmente en sistemas que tienen múltiples tipos de sistemas de archivos.
